# Portfolio — 정아린 · Arin Jung

부산대학교 디자인앤테크놀로지전공 정아린의 1페이지 포트폴리오 사이트입니다.

**Live:** https://wxxdkfls-ai.github.io/Portfolio_AI_python/

## 소개

디자인과 웹프로그래밍을 함께 다루는 학생 포트폴리오입니다.
밝은 미니멀 톤, 버건디 포인트 컬러, 한국어 줄바꿈(`word-break: keep-all`)을 고려해 제작했습니다.

- Hero / About / Toolkit / Projects / Contact
- 반응형 레이아웃 (320px ~ 데스크톱)
- 스크롤 진입 애니메이션, 현재 섹션 내비게이션, 이메일 복사
- `prefers-reduced-motion` 대응

## 구성

```
index.html    페이지 구조와 콘텐츠
styles.css    디자인, 반응형, 모션
script.js     내비게이션, 스크롤 애니메이션, 이메일 복사
```

## 로컬에서 보기

`index.html`을 브라우저로 열거나,

```bash
python -m http.server 8000
```

실행 후 http://localhost:8000 접속.
